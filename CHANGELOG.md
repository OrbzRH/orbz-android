# Changelog

## 0.1.0

First release.

- Sign in with an API key from the console's Keys page. Wallet sign-in from the app (WalletConnect) is built in and ships next.
- Home: available credit, the fuse on the oldest credit, the epoch clock, $ORBZ balance and eligibility, the month's usage.
- Chat with Orbz Opus, streamed, cost under every answer.
- Check any token or wallet on Robinhood Chain: facts, Orbz Opus's read, follow-ups.
- Receipts, every epoch.
- Session stored encrypted (Android Keystore), no backup, no analytics.
